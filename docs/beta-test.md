# onion MVP 베타 테스트 배포 가이드

테스터 약 100명에게 **무료·일시적으로** 앱을 배포하고 후기를 수집하기 위한 안내입니다.

## 1. 테스터 접속 방법 (설치 필요 없음)

앱은 웹으로 배포되어 QR 스캔 → 모바일 브라우저에서 바로 열립니다.

- **접속 주소**: https://jun317.github.io/onion_frontend_v1.2/
- **QR 코드**: `docs/qr-web.png` (인쇄물·카톡·포스터 어디든 사용)
- iOS·안드로이드 모두 동작. 별도 앱 설치 없음.
- 팁: 테스터에게 "홈 화면에 추가"를 안내하면 전체 화면(주소창 없이)으로 앱처럼 쓸 수 있어요.
  (Safari: 공유 → 홈 화면에 추가 / Chrome: ⋮ → 홈 화면에 추가)

### 공유용 문구 예시

> 🧅 경제 뉴스를 숏폼처럼 — onion 베타 테스트에 초대합니다!
> 설치 없이 QR만 찍으면 바로 열려요 (1~2분).
> 써보시고 앱 안의 "피드백 남기기"로 의견 부탁드려요 🙏

## 2. 피드백 폼 연결하기 (3분)

앱의 피드(맨 아래)와 마이 탭에 "피드백 남기기" 버튼이 있습니다.
현재는 이메일로 열리며, Google Form 을 만들면 폼으로 바뀝니다.

1. https://forms.new 접속 → 새 폼 생성 (무료, 응답 자동 집계)
2. 아래 권장 문항 붙여넣기
3. 보내기 → 링크 복사
4. `src/constants/links.ts` 의 `FEEDBACK_FORM_URL = ''` 에 URL 붙여넣기 → 커밋/푸시 (자동 재배포)

### 권장 설문 문항 8개

1. 첫인상은 어땠나요? (매우 좋음~매우 별로, 5점)
2. 뉴스 내용이 이해하기 쉬웠나요? (5점)
3. "그래서 어떻게 되나요?" 섹션이 판단에 도움이 됐나요? (5점)
4. 스테디(장기 이슈) 페이지를 봤다면, 흐름 파악에 유용했나요? (5점 + 안 봤어요)
5. 속도·오류 등 불편했던 점이 있었나요? (주관식)
6. 지인에게 추천할 의향이 있나요? (0~10, NPS)
7. 가장 좋았던 것 / 가장 아쉬웠던 것 하나씩 알려주세요 (주관식)
8. 연령대를 알려주세요 (10대~50대+, 선택)

## 3. 배포가 동작하는 방식

**최초 1회 설정 (저장소 주인만, 30초):** GitHub → 저장소 **Settings → Pages →
"Build and deployment" → Source 를 "GitHub Actions" 로 선택**.
(봇/워크플로 토큰은 Pages 를 처음 켜는 권한이 없어, 이 토글만 사람이 한 번 눌러야 해요.
백엔드 저장소에서 Pages 를 켰던 것과 같은 설정입니다.)

그 뒤부터는:
- `.github/workflows/deploy-web.yml` 이 기본 브랜치 push 마다 자동으로:
  Expo 웹 빌드(`npx expo export -p web`) → GitHub Pages 배포.
- 수동 재배포: GitHub → Actions → deploy-web → Run workflow.
- 데이터는 백엔드 저장소의 MVP 패키지(out_mvp)에서 그대로 로드 — 웹/네이티브 동일.

## 4. 테스트 종료(배포 내리기)

"일시적 배포"이므로 끝나면 이렇게 내립니다:
- 저장소 Settings → Pages → Source 를 None 으로 (즉시 접속 차단), 또는
- `.github/workflows/deploy-web.yml` 삭제 (재배포 중단, 마지막 배포는 유지됨).

## 5. (선택) 네이티브로 보여주고 싶을 때 — Expo Go

웹보다 스와이프 감이 좋은 네이티브 경험을 원하는 테스터용. Expo 계정 로그인이 필요해
직접 실행해야 합니다:

```bash
npm install -g eas-cli
eas login                 # Expo 계정 (무료)
eas update:configure      # 최초 1회 — app.json 에 projectId 추가됨
eas update --branch beta --message "MVP beta"
```

완료되면 터미널에 나온 링크/QR 를 공유 → 테스터는 **Expo Go 앱(무료)** 설치 후 QR 스캔.
무료 플랜은 월 1,000명까지 — 100명 테스트에 충분합니다.
주의: 테스터의 Expo Go 가 SDK 54 를 지원해야 합니다 (AGENTS.md 참고).

## 6. 유의사항

- 웹 버전 한계: 브라우저 특성상 스와이프 감이 네이티브보다 약간 덜하고,
  iOS Safari 는 주소창이 화면 일부를 차지합니다 ("홈 화면에 추가"로 해소).
- 후기·이용 기록(스트릭·단어장)은 테스터 기기 브라우저에만 저장됩니다 (서버 수집 없음).
